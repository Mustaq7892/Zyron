# Zyron Learning Notes

## APIs (Application Programming Interface)

API = A way for one software system to communicate with another software system.

Client = The system making the request.

Server = The system answering the request.

Request = Message sent to server.

Response = Message returned from server.

## HTTP Methods (HyperText Transfer Protocol)

GET = Read Data

POST = Create Data

PUT = Update Data

DELETE = Delete Data

## JSON ((JavaScript Object Notation))

JSON = Standard format used to exchange data.

Example:

{
  "name": "Mustaq"
}

## Status Codes

200 = Success
401 = Unauthorized
404 = Not Found
500 = Server Error
